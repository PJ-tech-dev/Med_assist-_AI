# Contributing to MedAssist AI 🤝

First off, thank you for considering contributing to MedAssist AI! It's people like you that make open-source healthcare tools better for everyone.

This document serves as a guide for how to collaborate, propose features, and submit your code.

## 🛠️ How to Contribute

### 1. Fork and Clone the Repository
Start by forking the repository to your own GitHub account. Then clone it locally:
```bash
git clone https://github.com/YOUR-USERNAME/Med_assist-_AI.git
cd Med_assist-_AI
```

### 2. Create a Feature Branch
Before you make any changes, always create a new branch for your feature or bug fix:
```bash
git checkout -b feature/your-amazing-feature
```
*(Use descriptive names like `feature/add-dark-mode` or `fix/sos-routing-bug`)*

### 3. Make Your Changes
Make your code changes in your local environment. Be sure to test your changes:
- If changing the backend, run the FastAPI server locally (`python main.py`).
- If changing the frontend, run the Next.js server locally (`cd frontend && npm run dev`).

### 4. Commit Your Changes
Write clear, concise commit messages describing what you changed and why:
```bash
git add .
git commit -m "Add: Implemented new XYZ feature in the medical agent"
```

### 5. Push to Your Fork
Push your new branch up to your GitHub fork:
```bash
git push origin feature/your-amazing-feature
```

### 6. Open a Pull Request (PR)
1. Go to the original `PJ-tech-dev/Med_assist-_AI` repository on GitHub.
2. You will see a prompt to **"Compare & pull request"**. Click it.
3. Provide a clear title and a detailed description of what your code does.
4. Submit the Pull Request! The project maintainers will review your code, request any necessary changes, and merge it into the main branch.

## 🐛 Found a Bug?
If you find a bug in the source code, you can help us by submitting an Issue to our GitHub Repository. Even better, you can submit a Pull Request with a fix!

## 💡 Proposing Enhancements
If you have a major feature idea, please open an Issue first to discuss it with the maintainers before writing a lot of code. This ensures your time is well spent and aligns with the project's roadmap.

---
*Happy coding, and thank you for helping build the future of AI healthcare!*
